# Command: /seo backlinks

**Modifies files:** No — this is a strategy/recommendation command. This skill does not perform outreach, publish to third-party sites, or acquire links directly.

## Purpose

Produce an ethical off-site authority-building strategy: linkable-asset ideas, digital PR angles, and legitimate link-earning opportunities.

## Procedure

1. Run `workflows/backlink-strategy.md`.
2. If competitor context would sharpen the recommendations, run `workflows/competitor-analysis.md` first (specifically the backlink-profile-observation section, if data is available).
3. Any recommended linkable asset that's actually a content piece should also be logged in `templates/content-roadmap.md` so it flows into normal content execution.

## Hard constraint

Per [[../rules/no-black-hat]], never recommend PBNs, link farms, paid/undisclosed links, automated link exchanges, comment/forum spam, or any scheme whose primary purpose is manipulating ranking signals rather than earning genuine citation. If explicitly asked for one of these, decline and explain the risk rather than complying or offering a "softer" version.

## Output

A prioritized list of legitimate authority-building opportunities, clearly labeled as strategy/recommendations rather than a guarantee of specific link acquisition.
